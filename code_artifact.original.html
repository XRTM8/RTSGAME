📋 دليل القيادة والتحكم المثالي

1. رسم خط التشكيل والتوجيه (أقوى أداة تكتيكية):
اسحب بـ الزر الأيمن للماوس (أو فعّل زر "أمر تحرك/خط" بالأسفل واسحب بالماوس أو الإصبع) لترسم خطاً حياً على الورقة؛ سيتوزع الجنود فوراً على طول الخط الذي رسمته ويوجهون أكتافهم وبنادقهم نحو العدو!
2. التحديد الذكي وتقسيم الفصائل:
اسحب بالزر الأيسر لتحديد مجموعة جنود داخل إطار، أو استخدم أزرار الفصائل السريعة بالأسفل (الكل [1]، فصيلة الاقتحام [2]، فصيلة الإسناد والقناصة [3]).
3. التحكم الحركي المباشر (WASD / الأسهم):
يمكنك في أي لحظة تحريك الجنود المحددين مباشرة باستخدام مفاتيح WASD أو الأسهم مع توجيه نيرانهم نحو مؤشر الماوس!
4. التغطية، الخنادق، والقدرات:
الجنود خلف أكياس الرمل أو داخل الخنادق المرسومة يكتسبون درع تغطية يقلل إصاباتهم بشكل كبير. استخدم القنبلة اليدوية (G) لكسر تحصينات العدو والستار الدخاني (F) للتقدم الآمن.
